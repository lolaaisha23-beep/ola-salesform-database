# ola-salesform-database
## Workbook Overview
The workbook contains multiple worksheets designed to handle sales recording, customer information, product pricing, and automated data storage. It serves as a small business sales automation tool for managing daily transactions efficiently.
---
## Main Features
1. Automated Sales Form
The workbook includes an interactive Sales Form where users can enter:
- Customer Name
- Phone Number
- Product Type
- Quantity Purchased
- product Price
- Discount Allowed
- Total Amount
- Balance
- Date of Transaction
- Sales Representative Name
The form is designed with formatted input fields and command buttons to simplify data entry and reduce manual errors.
## Problems Solved by the Automation
- Elimination of Manual Record Keeping
- Reduction of Calculation Errors
- Faster Sales Processing
- Centralized Sales Database
- Improved Data Accuracy and Consistency
## Key Performance Indicators (KPIs)
The macro-enabled sales automation workbook can be evaluated using the following KPIs
- Sales Transaction Volume.
- Revenue Generated
- Average Sales per Transaction
- product Sales Performance
- Data Entry Accuracy Rate
- Transaction Processing Time
- Daily/Monthly Sales Trends
